Modules

Seven fewer apps in your Dock.

Every module switches on or off with one click. What you don't use costs nothing.

Keep awake

Like Amphetamine: indefinitely, with a timer or until a given time. Stays awake with the lid closed, stops when the battery runs low and turns itself on when you plug in the charger or a display.

☕ time left in the menu bar

⌘Tab by windows

Switch between windows, not apps, with live thumbnails. Type to search and act without letting go: close, minimize, hide or quit.

⌘ Tab or ⌥ Tab · ⌘ W ⌘ M ⌘ H ⌘ Q

Dynamic notch

Hover the notch and it expands: music, a file tray with AirDrop, calendar, sound, timer and performance. Connect your AirPods and you get the iPhone animation. It hides in full screen and gives a gentle haptic tap when it opens.

Adapts to every MacBook's notch; on Macs without one, as an island

Window shortcuts

Halves, quarters, thirds, almost maximize, larger or smaller, restore, next display. Drag to an edge and see the footprint before you drop. Save whole layouts and bring them back with a number.

⌃⌥ ← ⌃⌥ → ⌃⌥ ⏎ · ⌃⌥ 1…9 layouts

Clipboard history

Text, images and files. Search by typing, pin what you always use, pause when copying something sensitive. In memory by default; on disk if you choose.

⇧⌘ V opens the history · ⌥ P pins

Tools

Copy the text of any part of the screen (OCR), grab a colour, mute the microphone with a shortcut, lock the keyboard to clean it, hide desktop icons and guard against accidental ⌘Q.

⇧⌘ 2 text · ⇧⌘ 6 colour · ⌃⌥⌘ M mic

Sound

A different volume for every app, instant switching of speakers or microphone, balance and mute. It follows your Mac's volume keys in real time.

⌃⌥⌘ O cycles the output

FAQ

What you'll want to know.

Which permissions does it ask for?

Accessibility to move windows and show ⌘Tab; Screen Recording for thumbnails and OCR; Calendar only if you enable that notch tab; and "record system audio" only if you lower an app's volume. Each is requested when needed, never before.

Does anything leave my Mac?

No. No accounts, no analytics, no servers. The only thing that touches the Internet is the update check (GitHub), and you can turn it off.

Which Macs does it run on?

Any Mac running macOS 14.2 (Sonoma) or later, Apple silicon or Intel. The dynamic notch reads the real notch size of each display (14- and 16-inch MacBook Pro since 2021, 13- and 15-inch MacBook Air since 2022) and places the tabs so nothing hides underneath; on external displays or Macs without a notch it works as a small island, and you can also switch that module off and keep the other six.

How does it update?

By itself. OmniMac checks once a day for a new version and offers it; the package is signed and verified before installing. Also from the menu: "Check for updates…".

Why does macOS warn when installing?

Because it isn't signed with an Apple developer account ($99 a year, and OmniMac is free). The warning appears only the first time: go to System Settings › Privacy & Security and click "Open Anyway". The code is public, so you can check exactly what it does or build it yourself.

How do I uninstall it?

Drag the app to the Trash. If you used closed-lid mode, the scripts/uninstall.sh script in the repository also removes the system rule that enables it. Nothing else is left behind.

Is it really free?

Yes, and open source (MIT licence). If it saves you time every day, you can buy me a coffee or support the project on GitHub Sponsors.
