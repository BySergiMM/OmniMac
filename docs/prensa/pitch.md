Hola,

Soy Sergi, desarrollador español. Acabo de publicar OmniMac, una app de barra de menús gratuita y de código abierto que reúne en un solo proceso lo que muchos instalamos por separado: mantener el Mac despierto, ⌘Tab por ventanas, un notch dinámico con música, AirDrop y tarjeta de AirPods, atajos de ventanas, historial del portapapeles, OCR de pantalla y volumen por app.

## 9to5Mac (tips@9to5mac.com) · MacStories (formulario) · en inglés

**Subject:** OmniMac: one free, open-source menu-bar app replacing five Mac utilities (with measured resource usage)

Hi,

I'm Sergi, an indie developer from Spain. I've just released OmniMac, a free and open-source menu-bar app that bundles what many of us install separately: keep-awake, ⌘Tab by windows, a dynamic notch with music, AirDrop and an iPhone-style AirPods card, window snapping, clipboard history, screen OCR and per-app volume.

The angle I think fits your readers: it's measured. 0.017 % CPU, 19–27 MB of real memory and under one wake-up per second at idle, versus 636 MB for the five apps it replaces, with the methodology published in the repo. Native Swift, universal binary, macOS 14.2+, no accounts, no telemetry.

- Site with GIF and real captures: https://bysergimm.github.io/OmniMac/en/
- Code (MIT): https://github.com/BySergiMM/OmniMac
- Direct download: https://github.com/BySergiMM/OmniMac/releases/latest/download/OmniMac.pkg

Happy to send screenshots at any size or answer technical questions.

Best,
Sergi
