## Works on Macs without a notch

OmniMac derives the island from **the screen**, not from the model: it reads the safe
area, and when there isn't one it draws a floating island sized to the display. So it
works on an iMac, on a Mac mini with an external monitor, and on a 2019 MacBook — not
just on a 2021+ MacBook Pro.

To be straight about it: OmniMac isn't the only one that does this. [Notchy](https://notchy.dev/)
does it too, and it's free — though closed source. [Atoll](https://github.com/Ebullioscopic/Atoll)
is open source but needs a notched MacBook. What's unusual here is having the island
*and* ten other utilities in the same 16 MB process, under MIT, with the idle cost
measured and published.

## What it replaces

| Instead of | You get | Costs |
|---|---|---|
| Amphetamine | Keep awake, closed-lid mode, triggers | Free |
| Rectangle | Window shortcuts, drag-to-snap, saved layouts | Rectangle Pro is paid |
| Maccy | Clipboard history with images, files and pins | Free |
| AltTab | ⌘Tab by windows, with live thumbnails | Free |
| SoundSource | Per-app volume + 10-band equaliser | $47 |
| TextSniper | Copy text from the screen (OCR) | $7 |

It doesn't replace everything [Ice](https://github.com/jordanbaird/Ice) does (its menu-bar
hider is much simpler) or [Stats](https://github.com/exelban/stats) (that one reads fans and far
more sensors). Both are excellent — go install them if that's what you need.

## Everything it does

| Module | What it does |
|---|---|
| ▮ **Dynamic notch** | Hover and it expands: music, a file tray with AirDrop, today's calendar, sound, timer and Pomodoro, performance. Sneak peek on track change, an iPhone-style card when AirPods connect. Works without a notch. |
| ☕ **Keep awake** | Indefinitely, on a timer, or until a given time. Stays awake with the lid closed, stops on low battery, turns on with the charger or an external display. |
| ⌘ **⌘Tab by windows** | All your windows, not just apps, with live thumbnails. Type to search; ⌘W / ⌘M / ⌘H / ⌘Q act on the highlighted one. |
| ▭ **Window shortcuts** | Halves, thirds, quarters, almost-maximize, next display. Drag to an edge to snap. Layouts saved on ⌃⌥1…9, like radio presets. |
| 📋 **Clipboard** | Text, images and files. Search, pins, pause, optional persistence. **⌥⇧⌘V pastes without formatting**, and it can strip tracking from links as you copy them. |
| 🔊 **Sound** | Per-app volume, a **10-band equaliser** (global or per app) with nine presets, boost past 100 % with a limiter, output priority, and a standalone mixer on ⌃⌥⌘V. |
| 📈 **Performance** | Per-core CPU (efficiency vs performance), GPU, memory with pressure, disk, network, **temperature**, and **which apps are eating your Mac**. Alerts when something goes wrong. |
| 🛠 **Tools** | OCR (⇧⌘2), colour picker (⇧⌘6), mic mute, keyboard lock for cleaning, hide desktop icons, hold-to-quit guard, and dimming **below macOS's minimum brightness**. |
| ⌘ **Command bar** | ⌥Space and type: every OmniMac feature and every app. Off by default — ⌥Space belongs to Raycast for a lot of people. |
| 🫥 **Menu bar** | Hides the icons you don't use every day. |
| 🗑️ **App cleaner** | Uninstalls an app with everything it leaves behind, and finds leftovers from apps you already deleted. Everything goes to the Trash. |
| 📦 **Downloads** | Offers to install the apps you download as `.dmg`, then ejects and bins the image. Always asks first. |

Every module can be switched off, and a switched-off module frees its resources and
disappears from the menu.

## Why it's light

**0.017–0.033 % CPU and 86 MB at idle** (33–37 MB of real memory), measured with a published,
reproducible method — the scripts are in the repo.

The rule the whole app is built on: **nothing polls when nothing is visible.** The
performance charts only sample while you're looking at them. The notch stops all work
when it folds. The audio engine isn't even created unless you've set something to apply.

| | OmniMac | Amphetamine | AltTab | Rectangle | Maccy | BoringNotch | Ice | FineTune |
|---|---|---|---|---|---|---|---|---|
| CPU at idle | **0.017–0.033 %** | 0.000 % | 0.020 % | 0.040 % | 0.020 % | 0.340 % | 0.040 % | 0.000 % |
| Memory (RSS) | **86 MB** | 100 MB | 212 MB | 84 MB | 91 MB | 149 MB | 99 MB | 116 MB |

Those seven together take **851 MB**. OmniMac does their job with **86 MB**.

## Install

```bash
brew install --cask BySergiMM/tap/omnimac
```

Or download [`OmniMac.pkg`](https://github.com/BySergiMM/OmniMac/releases/latest/download/OmniMac.pkg) and open it.

> **First launch:** OmniMac isn't signed with a paid Apple developer account, so macOS
> will refuse to open it. Go to System Settings › Privacy & Security and click
> **Open Anyway**. Sorry — that's $99/year I haven't spent yet.

Requirements: macOS 14.2 (Sonoma) or later, Apple silicon or Intel.

## Permissions

Each one is asked for only when a feature needs it, never at launch.

| Permission | What needs it |
|---|---|
| Accessibility | Window management, ⌘Tab, paste from the clipboard |
| Screen Recording | ⌘Tab thumbnails, OCR, colour picker |
| Calendar | Only the notch's calendar tab |
| Audio capture | Only per-app volume and the equaliser |

Nothing leaves your Mac. No accounts, no analytics, no servers. The only network call
is the update check against GitHub, and you can turn it off.

## Known limitations

- Built as a universal binary, but only tested on Apple silicon.
- Not notarized: macOS will warn on first launch (see above).
- The notch reads Spotify and Music via AppleScript, so it doesn't pick up
  "now playing" from other apps.
- Album art only shows for Spotify — Music doesn't expose an artwork URL.
- Clipboard history lives in memory unless you turn on "save to disk" (unencrypted).
- macOS won't let *any* app remove `~/Library/Containers` folders, so the cleaner
  marks those "Finder only" instead of failing silently.
